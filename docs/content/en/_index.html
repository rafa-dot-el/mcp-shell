What is MCP Shell?

MCP Shell is a modern, secure CLI tool that implements the Model Context Protocol (MCP) for safe shell command execution. Built with Go for performance and reliability, it provides AI systems with controlled access to system shells across all major platforms.

Quick Installation

Nix (Recommended)

Reproducible builds and dependency management

# Run directly
nix run github:rafa-dot-el/mcp-shell

# Install to profile
nix profile install github:rafa-dot-el/mcp-shell

Binary Download

Pre-built binaries for all platforms

# Linux
curl -L https://github.com/rafa-dot-el/mcp-shell/releases/latest/download/mcp-shell_linux_amd64.tar.gz | tar xz

# macOS
curl -L https://github.com/rafa-dot-el/mcp-shell/releases/latest/download/mcp-shell_darwin_amd64.tar.gz | tar xz
