## Bug Management Process

### Severity Levels

- **Critical**: System crashes, data loss, security vulnerabilities
- **High**: Major feature broken, significant performance degradation
- **Medium**: Minor feature issues, usability problems
- **Low**: Cosmetic issues, edge cases, minor inconveniences

### Priority Guidelines

1. **Critical bugs**: Fix immediately, hotfix if needed
2. **High priority**: Fix in current sprint/milestone
3. **Medium priority**: Fix in next release cycle
4. **Low priority**: Fix when time permits

### Reporting Bugs

Users can report bugs via:
- [GitHub Issues](https://github.com/rafa-dot-el/mcp-shell/issues)
- Email to <>
- Community discussions

### Bug Verification

Before adding to this document:
1. Reproduce the bug consistently
2. Check if it's already reported
3. Verify it's not a configuration issue
4. Confirm it's actually a bug, not expected behavior
